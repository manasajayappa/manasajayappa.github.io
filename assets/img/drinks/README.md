# Drink photos for the Starbucks case study

Drop six JPGs in this folder with these exact names. Each one replaces its
illustration automatically the next time the page loads. Until a file is here,
the original illustration stays on screen — nothing breaks if you only add some.

| File | Mood tab | What to look for |
|---|---|---|
| `energize.jpg` | Energize | Iced coffee / shaken espresso in a clear cup with a straw |
| `calm.jpg`     | Calm Down | A hot tea, ideally amber/golden, in a cup or takeaway cup |
| `focus.jpg`    | Deep Focus | An iced matcha latte — green over milk |
| `cozy.jpg`     | Get Cozy | A hot latte with whipped cream and caramel |
| `social.jpg`   | Be Social | A pink strawberry drink, ideally in a clear cup |
| `refresh.jpg`  | Refresh | A mango / tropical drink, orange-yellow |

## Before you commit them

They display at 172x215, so download the *small* or *medium* size, not the
original. Aim for roughly 500x625 and under ~120 KB each. Anything much larger
just slows the page down for no visible gain.

To check what you ended up with:

    du -h assets/img/drinks/*.jpg
